# /sdd-status

1. 运行 `SDD status`。
2. 如果用户要细节，再运行 `SDD task list`、`SDD decision list`、`SDD evidence list`。
3. 用一屏中文报告，不要贴原始 JSON：
   - 项目与版本
   - 阶段与门禁
   - 当前 feature
   - 任务统计与活动任务
   - 开放/阻塞决策
   - 最近 handoff
   - 下一步（可执行动作）
4. 如果门禁失败，指出具体失败项和负责角色；不要只说“失败了”。
