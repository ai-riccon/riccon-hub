# riccon-hub 项目章程

## 核心原则

### 一、项目文档一律使用中文

项目内所有面向人的文档一律使用简体中文撰写，包括但不限于：`.specify/` 下的章程、评估产物（intake、research、define、shape、decide）、规格说明（spec）、实施计划（plan）、任务清单（tasks）、检查清单（checklist）、评审报告、ADR、README、发布说明与运维手册。

具体规则：

- **不翻译标识符与专名**：代码标识符、文件路径、命令、API 名称、配置键、日志字段、产品名与技术栈名称（如 RAGFlow、Spring Boot、React、Docker、MySQL）保持原样。
- **机器可读标记保持原样**：`[NEEDS CLARIFICATION: …]`、`Slug`、类型枚举（如 `new-capability`）及模板占位符保留英文 token，其后的内容用中文填写，以免下游流程解析失败。
- **引用保持原文**：引用的原始需求、外部文档摘录与错误信息按原文记录，必要时附中文说明；不以翻译替代原文引用，也不改写原文语义。
- **直接以中文成文**：新文档直接使用中文撰写，不先写英文再翻译；既有文档在其所属流程下次修改时同步转为中文，不做与当前任务无关的大规模重写。

## 治理

- 本约定为项目长期约定，适用于所有当前及后续阶段的文档产物。
- 修改本章程须获得项目负责人明确授权，并在文末更新版本号与最后修订日期。
- 文档约定与其他做法冲突时，以本章程为准；发现文档不符合中文约定时，在该文档所属流程中修正。
